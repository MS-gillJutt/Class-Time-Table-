# ClassTime — Smart Timetable Generator

**Live app:** https://classtimepk.netlify.app

ClassTime builds conflict-free school timetables: add classes, teachers and subjects, set the periods and breaks, and ClassTime generates a complete weekly timetable that respects teacher availability and avoids clashes. Built for schools in Pakistan that still make timetables by hand.

## Features

- Classes, teachers and subjects management
- Automatic weekly timetable generation (no double-booked teachers)
- Per-class and per-teacher views, printable output
- Admin area protected by a PIN

## Tech

- React + Vite + Tailwind CSS
- Static hosting on Netlify's free tier; data stays in the browser

## Repository contents

This repository stores **text source code only**. Binary assets (images and icons) are **not stored in git** — they ship inside the deploy package.
